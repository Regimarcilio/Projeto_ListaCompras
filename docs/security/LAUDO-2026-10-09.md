## Evidências e correções

### S1 — APKs debug distribuídos (ALTA, A08 Integrity Failures)
- **Evidência:** `ls *.apk` → v1.2–v2.0 todos `*-debug.apk` (16MB); `app/build.gradle.kts`: `release { minify+shrink }` existe mas sem keystore neste ambiente (`~/.android-keystores` ausente) nunca gerou release desde a v1.1. Debug = `debuggable=true`: qualquer um com USB depuração anexa debugger, lê memória e extrai o banco sem root.
- **Correção:** só distribuir release (`./gradlew :app:assembleRelease`); guardar keystore+senhas fora do repo (issue #11 já aberta e bloqueada nisso).

### S2 — `allowBackup=true` (MÉDIA, A04)
- **Evidência:** `AndroidManifest.xml:8` `android:allowBackup="true"`; banco Room (histórico de compras, estabelecimentos, preços) + DataStore saem inteiros num `adb backup`.
- **Correção:** `android:allowBackup="false"` (app é single-device offline; export JSON já cobre portabilidade) ou `android:dataExtractionRules` excluindo o `.db`.

### S3 — ANR no import de texto (MÉDIA, A10 Exceptional Conditions)
- **Evidência:** `ListaAtiva.kt:196 importarTexto()` é `suspend` mas roda no `viewModelScope` (Main); `share/ImportarTexto.kt:24-31` regex lazy `(.+?)\s*[—–-]` é O(n²) em linha longa sem traço; `EXTRA_TEXT` pode chegar a ~1MB via Binder. App malicioso local + usuário colando/confirmando = ANR.
- **Correção (3 linhas):** `texto.take(200_000)` na entrada + `withContext(Dispatchers.Default) { parseListaTexto(..) }` + botão Confirmar desabilitado durante o parse.

### S4 — Import JSON permissivo (BAIXA, A08)
- **Evidência:** `ImportExport.kt:77` `launcher.launch(arrayOf("application/json", "*/*"))` aceita qualquer arquivo; `DownloadsHelper.lerUri` lê bytes ilimitados (OOM em arquivo gigante); `JsonCodec.import` confia no `id` do arquivo — `@Insert` sem estratégia aborta e os itens caem na lista existente (mescla silenciosa).
- **Correção:** só `application/json`, teto de ~5MB antes de ler, e `OnConflictStrategy.REPLACE`/id novo na importação.

### S5 — Backup em Downloads público (BAIXA, A04)
- **Evidência:** `AutoBackupHelper.rodarSeNecessario()` escreve JSON completo silenciosamente em `Download/ListaCompras/` (MediaStore, visível a outros apps com acesso a mídia).
- **Correção:** pedir confirmação no primeiro backup ou mover para `cacheDir` + share manual; documentar no README.

### S6 — SDK 34 defasado (BAIXA, A02 Security Misconfiguration)
- **Evidência:** `compileSdk/targetSdk = 34` (2026: 35/36 vigentes) — perde comportamentos de segurança novos (16KB pages, edge-to-edge forçado, photo picker).
- **Correção:** subir para 35 após teste de regressão no aparelho.

### Pontos fortes (verificados, sem achado)
- **Segredos:** grep `AKIA|PRIVATE|api[_-]?key|token|ghp_` → só falsos positivos em comentários. Sem backend/keys no app.
- **Rede:** zero permissões (`INTERNET`, SMS, localização ausentes); exfiltração/C2 inviável por design.
- **Injeção SQL:** 100% Room com parâmetros ligados (`:tipo`, `:listaId`, `:ean`); `LIKE '%'\|\|:q\|\|'` com bind — sem concatenação.
- **Receiver ACTION_SEND:** valida `action + type=text/plain`, exige confirmação do usuário, `singleTop` + `setIntent` corretos.
- **FileProvider:** só `cache-path export/`, `exported=false` — privilégio mínimo; grant de leitura pontual no share.
- **Cripto/dados:** DataStore só guarda tema/backup (nada sensível); sem WebView/JS; sem `Log` com PII; sem `exec`.
- **CI:** `android-ci` verde (testes + lint); sem segredos no workflow.

## Pontos de atenção (não-bloqueantes)
1. `themes.xml` + `android:theme` legados no manifest (Compose cobre, mas alinhar).
2. Sem `FLAG_SECURE` (aceitável: lista de compras não é dado sensível).
3. Deps 2024 (AGP 8.5.2, Kotlin 2.0.21, Room 2.6.1, BOM 2024.06) sem CVE crítica conhecida — adotar Renovate/Dependabot.
4. MigrationTest (#14) ainda não executado — roda com aparelho (`connectedDebugAndroidTest`).
